# ESP32-C6 + BME680 + BSEC + MQTT

Projekt za praćenje okolišnih parametara pomoću senzora BME680, Bosch BSEC biblioteke i Zephyr RTOS-a.

Podaci se šalju preko Wi-Fi mreže MQTT protokolom uz TLS zaštitu.

**Izvorni kod i dokumentacija:**

https://github.com/Dejan-R/esp32c6-bme680-bsec-mqtt

**Napomena:** Javni repozitorij ne uključuje sve Bosch BSEC ovisnosti i lokalne senzorske komponente potrebne za izgradnju potpune aplikacije.
