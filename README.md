# Zephyr RTOS Course

Praktični edukativni primjeri za **Zephyr RTOS**, programiranje u jeziku **C** i razvoj embedded sustava na platformi **ESP32**.

Repozitorij je organiziran u tematske cjeline. Svaka vježba zaseban je Zephyr projekt s izvornim kodom, konfiguracijskim datotekama i vlastitom `README.md` datotekom koja sadrži cilj, objašnjenje, postupak izgradnje, zadatke i pitanja.
